# Evolution of Female Representation in Cinema Over Time

## Project Description
This project analyzes how the representation of women in cinema has changed over time, approximately from 1950 to 2026. The analysis will focus on several aspects of gender representation in films, including the proportion of female versus male main characters, differences in screen presence, genre-specific patterns, and the age distribution of actresses compared to actors.

The project will also examine whether female-led films are perceived differently by audiences by analyzing movie ratings. In addition, Bechdel Test data will be used as an indicator of female interaction and representation in films.

The goal is to identify long-term trends and possible improvements or persistent inequalities in the portrayal of women in cinema.
